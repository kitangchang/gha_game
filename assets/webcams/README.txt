VOLCANO WEBCAMS
===============

The first six PNGs in this folder (sorted by file name) fill the webcam screen on
the ops room wall. The label comes from the file name, minus any leading number:
'3_ngauruhoe.png' shows as 'Ngauruhoe'.

Draw them in daylight; the game darkens them at night. Any size works; each cell
shows a centred crop, so keep the summit near the middle of the picture. When a
volcano task is open, steam rises from the centre of one of the views.

Press F5 in game to reload. The shipped images are simple placeholders from
tools/make_placeholder_webcams.py (--force redraws them).
